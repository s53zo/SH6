## Design decisions

The analytical model consumes `fullQsoData` and `fullDerived.scoring`. Display filters select already credited events and never invoke scoring on a subset. Historical state uses only events at or before the selected timestamp. Descriptive views and score-formula capabilities are separate so missing formula inputs cannot silently become a generic P × M calculation.

Elapsed UTC is the default denominator. Rolling windows show counts, actual observed span, and whether the window overlaps the beginning of available log evidence. Unrecorded time outside the log envelope is unknown. Each credit retains its full-log QSO index and scope.
